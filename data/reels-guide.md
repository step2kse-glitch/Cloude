# 릴스·쇼츠 제작 공식 — 공통 + 살림템 (template: "salim") — /reels 가 매번 읽는다

분야별 공식: 설교·말씀 → `data/reels-templates/sermon.md`, 정보 → `data/reels-templates/info.md`.

블로그 글과 같은 화자(`data/blogger-profile.md`), 같은 사실 규칙(지어내기 금지·협찬 표기·가족 사생활 보호)을 따른다.
블로그가 "검색해서 읽는 글"이라면 릴스는 "스크롤 멈추게 하는 15초"다.

## 기본 세팅
- 길이 10~25초 (정보가 많으면 30초까지). 컷 5~9개.
- 사진 컷 1.5~3초, 영상 컷 1.5~4초. 첫 컷은 2~2.5초 안에 끊는다.
- 세로 1080×1920. 가로 사진·영상은 자동으로 흐린 배경 위에 전체가 보이게 들어간다(fit 생략 = 자동).

## 구조 (기본형 — 매번 똑같이 쓰지 말 것)
1. **후킹 (0~2.5초)** — 상단 노란 박스 `hook.text`. 첫 컷은 결과가 가장 극적으로 보이는 사진/장면(After, 문제 상황 클로즈업).
2. **문제 공감 (1~2컷)** — 페르소나의 상황을 한 줄로. "아무리 닦아도 이틀이면 다시 냄새"
3. **해결 과정 (2~4컷)** — 손이 나오는 사용 장면. 단계별 자막 "① 뚜껑 열고" "② 끼우기만"
4. **결과 + 단점 1개 (1~2컷)** — 솔직함이 신뢰를 만든다. 협찬이어도 단점 생략 금지.
5. **마무리 (card 또는 마지막 컷)** — 저장·팔로우 유도 한 줄. "필요할 때 꺼내 보게 저장해 두세요"

## 후킹 패턴 (블로그와 같은 4종 — trends.md 최근 기록과 다르게)
- 손실 회피형: "이거 모르고 락스 3통 버렸어요"
- 현장 몰입형: "밤 11시, 또 올라온 배수구 냄새"
- 반전형: "닦는 게 아니라 막는 거였어요"
- 공감형: "배수구 냄새, 저만 이런 거 아니죠?"
후킹 문구: 2줄 이하, 한 줄 12자 이내. 물음표·숫자가 잘 먹힌다. 낚시성 과장 금지.

## 자막 규칙
- 한 컷 = 한 자막. 한 줄 14자 이내, 최대 2줄 (`\n`으로 줄바꿈). 말하듯 짧게.
- 같은 컷 안에서 문장을 나눠 보여주고 싶으면 `subs` 사용 (컷 기준 상대 시간).
- 광고 어휘 금지(강추·역대급·무조건·최저가·대박 남발). 브랜드명은 자막 전체 1~2회.
- 가격·사용 기간·용량 등 숫자는 메모·사진(가격표·패키지)에서 확인된 것만.
- 이모지는 자막당 0~1개.

## 협찬 표기 (생략 불가)
- `sponsored: true` + `disclosure` 짧은 라벨 → 영상 전체 구간 좌상단에 표시된다.
  - 제품 제공: "광고 · 제품 제공" / 원고료: "광고 · 원고료 받음" / 제품+원고료: "광고 · 제품+원고료" / 업체 지정 문구가 있으면 그것.
- 게시 문구(`captions.instagram`) **첫 줄**에도 `data/sponsored-disclosure.md`의 대가 유형별 문장을 넣는다.
- 업로드할 때 인스타 "유료 광고 라벨", 유튜브 "유료 프로모션 포함"을 켜라고 안내한다.
- 협찬 영상에 "내돈내산·광고 아님" 같은 거짓 부인 표현 금지 (렌더러가 막는다).

## 개인정보 (모자이크 필수)
- 아이 얼굴, 타인 얼굴, 번호판, 택배 송장, 동호수, 단지 표지, 아이 이름표·교복·학교 로고 → `blur` 영역으로 가린다.
- 좌표는 **보이는 화면 기준 0~1 상대값** `{x,y,w,h,reason}` (렌더러가 15% 여유를 자동 추가).
- 영상의 `blur`는 컷 전체 구간에 같은 자리로 고정된다. 대상이 움직이면 그 구간을 컷에서 빼거나 다른 구간을 쓴다.
- 화자 본인 얼굴도 기본 모자이크 (본인이 공개를 명시한 경우만 예외).

## 게시 문구
- 인스타: 첫 줄 후킹(협찬이면 표기 먼저) → 3~5줄 요약 (가격·구매처 등 확인된 사실) → 저장 유도.
- 해시태그 5~10개: 메인 키워드 1~2 + 살림 일반 3~4 + 상황 2~3. 동탄은 매장·생활권 영상일 때만.
- 유튜브 쇼츠 제목: 40자 이내, 메인 키워드 앞쪽. 설명 2~3줄.

## 업로드 시간대·주기 (사람이 직접 올린다)
- 살림 주부 타겟: 오전 9~11시, 밤 9~11시. 주 2~4회.
- 같은 영상을 인스타·유튜브에 올릴 땐 각 앱에서 올린다 (워터마크 없는 원본 사용).

## 스타일 (모든 분야 공통 — 값이 null이면 분야 기본값)

| 항목 | 값 | 느낌 |
|---|---|---|
| `look` 필터 | none 원본 · bright 화사하게 · warm 따뜻하게 · cool 시원하게 · vivid 선명하게 · film 필름(그레인·비네팅) · mono 흑백 · soft 몽글몽글 · moody 무드(차분·어둡게) · golden 노을빛 | 컷별 덮어쓰기 가능 |
| `textStyle` 자막 | outline 굵은 외곽선 · box 반투명 박스 · marker 형광펜 강조 · serif 명조 감성 · bigbold 대형 타이포 · minimal 미니멀 | 컷별 덮어쓰기 가능 |
| `textAnim` 효과 | none · fade 스르륵 · slide 아래서 올라옴 · words 한 단어씩(14단어 이하) | 컷별 덮어쓰기 가능 |
| `hookStyle` 후킹 | yellow 노란 박스 · serif 명조+금색 선 · block 흰 블록 대형 | 영상 전체 |

| 분야 기본값 | 필터 | 자막 | 효과 | 후킹 |
|---|---|---|---|---|
| salim 살림템 | bright | outline | fade | yellow |
| sermon 설교·말씀 | moody | serif | fade | serif |
| info 정보 | vivid | bigbold | words | block |
| basic 기본 | none | outline | none | yellow |

- 강조: 자막 안에서 `*단어*` → 스타일별 강조색(노랑·금색·형광펜). 한 자막에 1곳이 가장 효과적.
- 한 영상 안에서 필터를 3개 이상 섞지 않는다 (톤이 흩어짐). 자막 스타일은 1~2개.
- 자체 폰트: `assets/fonts/`에 고딕 1개 + 명조 1개(파일명에 serif·myeongjo·명조 포함) — 상업 이용 가능 라이선스만.
