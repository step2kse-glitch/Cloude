# 설교·말씀 릴스 공식 (template: "sermon")

`data/reels-guide.md`의 공통 규칙(사실 지어내기 금지, 모자이크, 자막 길이) + 아래 규칙.
목표: 15~30초 안에 **말씀 한 구절 + 메시지 한 줄**이 마음에 남게. 정보량보다 여백.

## 기본 스타일 (스토리보드에서 바꿀 수 있음)
- 필터 `moody`(차분·어둡게) — 노을·빛 사진이면 컷별 `golden`, 흑백 사진이면 `mono`
- 자막 `serif`(명조 감성), 효과 `fade`(스르륵), 후킹 `serif`(명조 + 금색 선)
- 배경음악: 잔잔한 피아노·현악 (저작권 프리만). 설교 원본 음성이 있으면 `audio: true` → 배경음악이 자동으로 줄어든다

## 성경 구절 (가장 중요 — 절대 규칙)
- **사용자가 붙여넣은 본문만 글자 그대로** 쓴다. 기억으로 인용·의역·요약해서 "말씀"처럼 표기 금지.
- 메모에 본문이 없으면: 채팅 모드는 묻고, 스튜디오 모드는 구절 카드를 만들지 말고 review.md "확인 필요"에 적는다.
- 출처는 카드의 `ref`에: `"ref": "마태복음 11:28 (개역개정)"` — 역본 표기 포함.
- 구절이 길면 핵심 절만, 줄은 4줄까지 (`card`). 줄바꿈은 의미 단위로.
- 역본 저작권: 개역개정·새번역 등은 저작권이 있다. 짧은 인용(한두 절)만, 장 전체 낭독 영상 금지.

## 구조 (기본형)
1. **후킹 (0~2.5초)** — 듣는 사람의 상태를 묻는 한 줄. "요즘 *많이 지치셨나요?*" / "기도가 막힐 때"
2. **공감 (1~2컷)** — 삶의 장면 사진(빛·길·바다·손) + 짧은 자막
3. **말씀 카드 (4~5초)** — `type: "card"`, `image`(흐리게 깔릴 사진) 또는 `background`, `text` = 구절, `ref` = 출처. 핵심 구절에 `*강조*`
4. **메시지 (1~2컷)** — 설교 핵심 한 문장. 대구·반전형이 잘 남는다. "쉼은 *멈춤*이 아니라 그분께 *맡김*입니다"
5. **축복·적용 (card)** — "오늘 하루 *평안*하시길 축복합니다" + `ref`에 교회명·채널명(사용자가 준 것만)

## 설교 영상(촬영본) 쓸 때
- 프레임 시트로 장면을 보고 핵심 구간 2~4개를 고른다. **Claude는 소리를 들을 수 없다** →
  설교자가 실제로 한 말을 자막으로 받아쓰지 않는다. 사용자가 메모에 붙여넣은 원고·요약 문장만 자막으로.
- 받아쓰기 자막이 필요하면 review.md에 "설교 원고(또는 해당 구간 말) 붙여넣기 필요"로 적는다.
- 성도·회중 얼굴이 보이면 `blur`로 가리거나 그 구간을 쓰지 않는다 (본인 동의 없는 얼굴 노출 금지). 아이는 반드시.
- 설교자 본인 얼굴은 사용자가 공개를 명시했을 때만 그대로.

## 금지
- 특정 교단·인물 비방, 정치적 주장, 헌금 유도 문구, 치유·기적 효과 단정 ("이 말씀 읽으면 병이 낫습니다" 등).
- 사용자가 쓰지 않은 간증·사연 만들기.

## 게시 문구
- 첫 줄: 후킹 문장 / 둘째 줄: 구절 출처 / 2~3줄 묵상 요약 / "함께 기도해요" 같은 담백한 마무리.
- 해시태그 5~8개: 말씀묵상·오늘의말씀·성경구절·(책 이름) 등. 과한 해시태그 금지.
