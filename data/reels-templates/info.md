# 정보 릴스 공식 (template: "info")

`data/reels-guide.md`의 공통 규칙(사실 지어내기 금지, 협찬 표기, 모자이크) + 아래 규칙.
목표: "저장" 버튼을 누르게 만드는 15~25초. 한 영상 = 한 주제, 3~5단계.

## 기본 스타일 (스토리보드에서 바꿀 수 있음)
- 필터 `vivid`(선명하게) — 음식·제품 사진이 어두우면 `bright`
- 자막 `bigbold`(대형 타이포), 효과 `words`(한 단어씩), 후킹 `block`(흰 블록 대형)
- **상단 고정 제목** `titleBar.text` — 영상 내내 주제가 보이게. 예: "배수구 냄새 없애는 법 *3가지*" (18자 이내)
  (후킹이 끝난 뒤부터 끝까지 자동 표시. `start`/`end`로 조절 가능)

## 구조 (기본형)
1. **후킹 (0~2.5초)** — 숫자 + 이득. "배수구 냄새\n*3가지*만 기억하세요" / "이거 모르면 *매달 손해*"
2. **단계 컷 (3~5컷, 각 2.5~3초)** — 자막은 번호로 시작: "① *베이킹소다* 반 컵". 핵심어 1개만 `*강조*`
   - 한 단어씩 효과는 단어 14개 이하일 때만 동작(넘으면 자동으로 스르륵). 단계 자막은 짧게.
   - 마지막 단계나 주의사항 컷은 `"textStyle": "marker"`(형광펜)로 바꿔 리듬을 준다.
3. **주의·단점 (선택, 1컷)** — "⚠ 락스와 *섞지 마세요*" 처럼 안전 정보는 확인된 것만.
4. **요약 카드 (card)** — "✔ 소다 ✔ 식초 ✔ 뜨거운 물" 한 화면 정리, 또는 저장 유도 "*저장*해두고 필요할 때 보세요"

## 사실 규칙
- 수치(양·시간·온도·가격)·효과는 **메모·사진·사용자가 준 자료**에 있는 것만. 없으면 빼고 review.md "확인 필요"에.
- 건강·의학·법률·금융 정보는 "단정"하지 않는다 ("~에 좋다고 알려져 있어요" 식 출처 없는 일반화도 금지 — 출처를 받으면 쓴다).
- 다른 사람 콘텐츠(책·영상·기사)를 요약하면 게시 문구에 출처 표기.

## 게시 문구
- 첫 줄: 제목 그대로 / 단계 요약 체크리스트 3~5줄 / "저장해두고 필요할 때 꺼내 보세요".
- 해시태그 5~10개: 주제 키워드 2 + 분야 3 + 상황 2~3.
