# 인스타그램 프로필 정돈 (@thinking_atelier1020)

API로는 프로필(이름·소개·사진), 하이라이트, 고정 게시물을 바꿀 수 없어서 앱에서 직접 바꿔야 합니다.

## 1. 이름 (검색에 걸리는 칸)
`김성은 목사 | 한 구절 묵상`

## 2. 소개 (150자 이내)

**A. 묵상 중심**
```
말씀 한 구절을 천천히, 깊이 묵상합니다
📖 한 구절 묵상 | 갈라디아서 · 에베소서 · 사사기 · 룻기
개혁주의 목사 · 생각공방
저장해 두고 한 주 동안 묵상해 보세요 ↓
```

**B. 청년사역과 함께**
```
청년사역자 · 설교자 | 생각공방
📖 한 구절 묵상 — 성경 한 권, 핵심 구절을 깊이
갈라디아서 · 에베소서 · 사사기 · 룻기
매주 새 구절로 찾아갑니다 ↓
```

## 3. 하이라이트
스토리에 `brand/highlight-*.png`를 올린 뒤 하이라이트로 묶고, 같은 그림을 표지로 지정합니다.
시작 · 갈라디아서 · 에베소서 · 사사기 · 룻기

## 4. 고정 게시물 (3개)
1. 시리즈 안내 (`guide-01`)
2. 룻기 01편
3. 갈라디아서 01편

## 5. 정리
- 같은 글이 여러 번 올라간 예전 게시물(2025-09-04 사마리아 여인 3개)은 하나만 남기고 보관
- 링크(bit.ly)가 지금도 열리는지 확인
