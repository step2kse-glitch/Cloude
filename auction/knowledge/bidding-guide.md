# 입찰·낙찰 후 진행 가이드 (리포트의 "진행 로드맵"에 물건별 날짜를 넣어 옮긴다)

> 법원·사건마다 다를 수 있는 값(보증금 비율, 입찰 마감 시각 등)은 **해당 법원 매각공고**로 확인하고 리포트에 "공고 확인" 표시.

## D-14 ~ D-3 : 임장 (현장 확인)

- ✔ 외관·층·향·누수 흔적, 우편함(점유자 이름·체납 고지서) — 사진은 공용부분만, 타인 사생활 촬영 금지
- ✔ 관리사무소: 체납관리비(전용/공용 구분), 장기수선충당금, 점유자 거주 여부
- ✔ 주민센터 **전입세대열람** (경매 이해관계인 자격으로 신청 가능 — 매각물건명세서 출력본 지참)
- ✔ 인근 중개사무소 2곳 이상: 실제 매도 가능가(급매가), 전세·월세 시세, 최근 경매 낙찰가 소문
- ✔ 대출: 경락잔금대출 가능 금액·금리 사전 상담 (DSR·주택수에 따라 변동) → `buyer.loanRatio` 업데이트
- 결과를 케이스 JSON(rentMarket·costs·buyer)에 반영하고 `node auction/src/cli.js evaluate` → `report` 재실행 (채팅: `/auction 임장 결과: ...`)

## D-1 : 최종 점검

- ✔ 대법원 법원경매정보에서 **변경·연기·취하** 여부 재확인 (취하·정지 잦음)
- ✔ 매각물건명세서 최신본 다시 확인 (기일 직전 수정되는 경우 있음)
- ✔ 입찰가 최종 결정: 리포트의 "상한"을 넘기지 않는다. 현장 분위기에 올리지 않기

## D-day : 입찰 (기일입찰 — 해당 법원 경매법정 직접 방문)

준비물:
- 신분증, 도장
- 입찰보증금: **최저매각가격의 10%** (재매각 사건은 보통 20%, 법원 공고 확인) — 자기앞수표 1장 권장
- 대리 입찰: 본인 인감증명서(발급 3개월 이내) + 인감 날인 위임장 + 대리인 신분증·도장
- 공동 입찰: 공동입찰신고서·지분 표시

입찰표 작성 주의 (무효·사고 1순위):
- ✔ 사건번호·물건번호 정확히 (물건번호 있는 사건은 필수)
- ✔ **금액 0 하나 더 쓰기 금지** — 쓰고 나서 자릿수 소리 내어 세기. 수정 불가, 새 용지에 다시
- ✔ 입찰가는 최저가 이상, 보증금 봉투 따로

개찰 후:
- 최고가매수인 → 영수증 수령
- 2등은 (최고가 − 보증금) 이상이면 **차순위매수신고** 가능
- 공유자 우선매수 신고가 들어오면 낙찰이 넘어갈 수 있음

## 낙찰 후 일정

| 시점 | 할 일 |
|---|---|
| 매각기일 + 7일 | **매각허가결정** (불허가 사유: 절차 하자, 농취증 미제출 등) |
| 허가결정 + 7일 | 즉시항고 없으면 **확정** |
| 확정 후 (보통 1개월 이내 지정) | **대금지급기한** 통지 → 잔금 납부 (경락잔금대출 실행). 미납 시 보증금 몰수 |
| 잔금 납부 즉시 | 소유권 취득. 법무사 통해 **소유권이전등기·말소촉탁**, 취득세 납부 (취득일부터 60일 내) |
| 잔금 납부와 동시 | **인도명령 신청** (대금 납부 후 6개월 이내만 가능 — 놓치면 명도소송) |
| 배당기일 | 임차인이 배당받으려면 낙찰자 **명도확인서 + 인감증명** 필요 → 이사와 맞교환하는 협상 카드 |

## 명도 (점유자 내보내기)

1. 첫 방문은 대화: 이사 일정·이사비 협의 (이사비는 법적 의무 아님, 협상용 — 리포트 "명도 계획"의 예상 비용 범위 내)
2. 합의 내용은 **합의서**로 (날짜·금액·지급 조건·원상 상태)
3. 불응 시: 인도명령 결정 → 송달 → 집행관 강제집행 신청 (집행비용 별도, 수 주~수개월)
4. 점유자에게 위협·무단 진입·단전단수 금지 (형사 문제)

## 출구 전략

- **매도**: 단기 양도세가 크다 (주택 1년 미만·2년 미만 중과). 보유기간을 리포트에서 시나리오별로 보여준다
- **임대**: 전세 세팅 시 보증금으로 투자금 회수 가능하나 역전세 위험 표시
- **실거주**: 시세 대비 할인율 = 이익. 주택수 변화에 따른 다른 집 세금 영향 표시
