# 경매로 내 집 찾기 가이드 (goal = 실거주일 때 Claude가 따르는 순서)

> 경매로 집을 사는 이유는 단 하나: **같은 집을 급매보다 싸게** 사는 것. 급매 대비 절약액이 명도 기간의 불편(입주 지연·임시 거처)보다 커야 의미가 있다.
> 리포트의 "실거주" 행 = 급매가로 일반 매매할 때와 비교한 절약액.

## 1. 예산부터 (얼마를 넣을 수 있나)

- 가용 현금 · 대출 비율(생애최초는 상한이 높을 수 있음 — 은행 상담값 사용) · DSR 한도를 확인한다.
- `node auction/src/cli.js budget` → 감당 가능한 최대 낙찰가. 검색 조건 `maxMinPrice` 는 이 값의 85~90%로 잡는다 (낙찰가는 보통 최저가보다 높다).
- 잔금일엔 낙찰가의 (1 − 대출비율) + 취득세 + 이전비 + 명도·수리비가 한꺼번에 필요하다. 입찰보증금(최저가 10%)은 그 안에 포함된다.
- 생애최초 취득세 감면(`buyer.firstHome: true`), 기존 집 처분 계획(일시적 2주택)을 질문해 확인한다.

## 2. 지역·단지 고르기 (사용자 기준 → criteria.json `home`)

질문 목록 (한 번에):
1. 직장 위치와 허용 출퇴근 시간 (부부 둘 다)
2. 아이 학교 필요 여부, 학년 (초등학교 도보 거리 중요)
3. 방 개수·면적 최소 조건, 층·엘리베이터 등 꼭 필요한 것
4. 입주 희망 시기 (지금 집 계약 만료일) — 명도 기간 + 잔금까지 4~6개월 걸리는 걸 감안
5. 절대 안 되는 조건 (예: 대로변, 오래된 복도식)

케이스마다 `homeFit` 을 채운다 (출처 있는 사실만, 모르면 ❓):
```json
"homeFit": { "commute": "○○역까지 버스 25분 (지도 검색)", "school": "○○초 도보 8분", "living": "마트·병원 도보권", "score": 4 }
```
점수(1~5): 사용자 우선순위 1순위 충족 +2, 2순위 +1, 3순위 +1, 절대 안 되는 조건 해당 시 0점(=후보 제외).

## 3. 실거주에서 특히 볼 위험

- **입주 시기**: 소유자 점유·보증금 손실 임차인 → 명도 3~5개월. 지금 집 만기와 겹치면 임시 거처 비용을 리포트에 적는다.
- **내부 상태 미확인**: 경매는 내부를 못 보고 산다 → 수리비를 넉넉히 (구축은 평당 100만 이상 가정 여부를 사용자와 상의).
- **대항력 임차인 인수**: 실거주자는 인수 보증금을 돌려줘야 입주 가능 → 현금 계획에 포함.
- **관리비 체납**: 공용부분 승계, 관리사무소에서 확인.
- **같은 단지 급매와 비교**: 절약액이 낙찰가의 5% 미만이면 급매 매수도 같이 검토하라고 안내.

## 4. 리포트 구성 (실거주 모드)

- "내 집 후보 순위" 표: 적합도 → 등급 → 절약액 순
- 물건별 "🏠 내 집으로서" + 입주 예상일
- 마지막에: "마음에 드는 후보가 있으면 임장 체크리스트를 그 집 기준으로 만들어 드릴게요."
