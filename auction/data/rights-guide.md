# 권리분석·물건평가 가이드 (Claude가 물건마다 그대로 대조)

> 근거 문서: **매각물건명세서**(가장 중요) · 등기사항전부증명서(등기부) · 현황조사서 · 감정평가서 · 문건/송달내역.
> 문서에서 확인한 것만 쓴다. 확인 못 한 칸은 "❓미확인"으로 남기고 "확인 필요 질문"에 올린다. 추정은 반드시 "추정"이라고 표기.

## 1. 말소기준권리 찾기

등기부 갑구·을구에서 **가장 빠른 날짜**의 아래 권리가 말소기준권리:
근저당 · 저당 · (가)압류 · 담보가등기 · 경매개시결정등기 · (배당요구했거나 경매신청한 전 소유자 대상 건물 전부) 전세권

- 말소기준 **이후** 권리 → 원칙적으로 소멸 (낙찰자 인수 없음)
- 말소기준 **이전** 권리 → 인수 위험. 아래 표로 하나씩 판정

| 권리 | 말소기준보다 앞서면 | 비고 |
|---|---|---|
| 지상권·지역권·전세권(배당요구 X) | 인수 | 전세권이 배당요구하면 소멸 |
| 가처분 | 인수 (소유권 다툼이면 치명적) | **선순위 가처분 = 기본 제외** |
| 소유권이전 청구권 가등기 | 인수 (본등기 시 소유권 상실) | 담보가등기인지 문건으로 확인 |
| 환매등기 | 인수 | |
| 임차권등기 / 대항력 임차인 | 보증금 중 배당 못 받은 금액 인수 | 2번 참조 |

**순위와 무관하게 늘 인수 가능**: 유치권 · 법정지상권 · 분묘기지권 · 예고등기(구법) · 건물철거·토지인도 가처분.
매각물건명세서 "매각에 따라 효력이 소멸되지 아니하는 것" 칸과 "비고"란을 글자 그대로 옮겨 적는다.

## 2. 임차인 분석 (주택)

각 임차인마다 표로:

| 항목 | 내용 |
|---|---|
| 전입일 (대항요건 = 전입 + 점유, **다음날 0시** 효력) | |
| 확정일자 | |
| 배당요구 여부 · 배당요구종기 내 신청했는지 | |
| 보증금 / 월세 | |
| 대항력 (전입 다음날 0시 < 말소기준 설정일?) | 있음 / 없음 |
| 예상 배당액 → 낙찰자 인수액 | |

판정 규칙:
- 대항력 **없음** → 배당 여부와 무관하게 인수 0. 명도 대상 (인도명령 가능).
- 대항력 **있음** + 배당요구 O + 확정일자로 **전액 배당** 예상 → 인수 0 (단 배당표 확정 전까지 명도 협조가 늦을 수 있음).
- 대항력 **있음** + 미배당 금액 → **그 금액을 인수**. `assumedAmount` 에 넣는다.
- 대항력 있음 + 배당요구 X → **보증금 전액 인수**.
- 현황조사서에 "점유자 불명·폐문부재"이고 전입세대열람으로 미확인 → 위험 "중", 질문 목록에 올림.
- 소액임차인 최우선변제 기준은 **최선순위 담보물권 설정일** 당시 지역 기준표 적용 (기준표는 웹 검색으로 확인하고 출처 적기).
- HUG·SGI 등 보증기관이 임차인 권리를 승계하고 "대항력 포기 확약서"를 낸 사건은 명세서 비고 문구로만 판정.
- 배당 계산 순서(간이): 경매비용 → 최우선변제(소액임차인·최종 3개월 임금) → 당해세 → 확정일자/담보물권 순위대로 → 일반채권.
  당해세·조세 체납액은 문건에서 확인될 때만 반영, 아니면 "❓".

## 3. 물건 자체 리스크

| 항목 | 확인 위치 | 기본 처리 |
|---|---|---|
| 지분매각 | 사건명·명세서 | 제외 (공유자 우선매수·명도 곤란) |
| 대지권 미등기 / 대지권 없음 | 명세서·감정서 | 제외 (미등기 사유가 단순 절차 지연이면 "중"으로 완화 가능, 근거 명시) |
| 토지별도등기 | 등기부 표제부 | 인수 조건 확인 전까지 "상" |
| 위반건축물 | 건축물대장·감정서 | 이행강제금 → 대출 불가 가능성 |
| 농지취득자격증명 필요 (농지) | 명세서 | 미제출 시 보증금 몰수 |
| 체납관리비 | 관리사무소 (임장 때 확인) | 공용부분만 낙찰자 승계 → `unpaidMgmtFee` |
| 재매각 사건 | 사건 이력 | 보증금 20% 등 법원 공고 확인, 전 낙찰자 미납 사유 추적 |
| 감정 시점 | 감정평가서 날짜 | 6개월 이상 지났으면 현재 시세와 괴리 체크 |
| 공부상 면적 ≠ 실제 | 감정서 | 차이 크면 감정가 신뢰 하락 |

## 4. 시세 산정 (반드시 출처)

- 우선순위: 국토부 실거래가(동일 단지·동일 평형·최근 6개월) > 같은 단지 현재 매물 호가(하한) > 인근 유사 단지.
- 사용자가 붙여넣은 자료나 웹 검색으로 확인한 숫자만 쓴다. 출처·조회일·건수를 `marketPrice.source` 에 적는다.
- `low` = 최근 실거래 하위값 또는 급매 호가, `mid` = 실거래 중앙값, `high` = 최근 최고 실거래.
- 확인할 수 없으면 숫자를 만들지 말고 "시세 미확인 → 계산 보류"로 보고.

## 5. 등급

| 등급 | 기준 |
|---|---|
| **A 입찰 권장** | 인수 권리 0, 대항력 임차인 없음 또는 전액 배당 확실, 물건 리스크 없음, calc 판정 "검토 가능", 필요현금 ≤ 가용현금 |
| **B 조건부** | 위 조건 중 1개가 "❓미확인" — 임장·서류로 해소되면 A |
| **C 관망** | 이익 마진 얇음(calc "관망"), 또는 명도 난이도 상, 또는 시세 하락 추세 |
| **X 제외** | 인수 금액이 이익을 넘음, 선순위 가처분·가등기, 유치권·법정지상권 신고, 지분·대지권 문제, 현금 부족 |

등급 이유를 한 줄로 반드시 같이 적는다.
