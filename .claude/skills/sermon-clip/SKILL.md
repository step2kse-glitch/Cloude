# 설교 클립 자르기

ECC의 `video-editing` 스킬(MIT, © Affaan Mustafa, 라이선스는 `.claude/skills/ECC-LICENSE.txt`)에서 필요한 부분만 골라, "오늘도 복음"에서 실제로 쓰던 방식과 합쳤다.

AI가 영상을 새로 만드는 것이 아니다. 실제 설교 영상을 빠르게 줄이고 정리하는 것이 목적이다.

## 순서
1. **원본 확보**: 원본 영상은 목사님 구글 드라이브에 있다. 컨테이너가 새로 시작되면 드라이브 로그인(OAuth)을 다시 해야 한다. 토큰은 scratchpad에만 두고 커밋하지 않는다.
2. **받아쓰기**: sherpa-onnx SenseVoice(한국어)와 silero VAD로 설교 전체를 문장 단위 시간과 함께 받아쓴다. 결과는 `sources/sermons/*.md`에 둔다.
3. **구간 고르기**: 받아쓰기를 읽고, 홀로 서는 메시지 구간을 6개 안팎 고른다.
   - 시작과 끝은 반드시 문장 경계로 한다. 중요한 말이 잘리지 않게 한다. 목사님이 가장 민감하게 보시는 부분이다.
   - 한 클립은 표지 0.5초를 포함해 약 84초 이하로 한다.
4. **다듬기**: 아래 FFmpeg 명령으로 자르고, 버벅거림과 침묵을 빼고, 소리를 맞춘다.
5. **검증**: 자른 클립을 다시 받아쓰기해서 첫 문장과 끝 문장이 온전한지 확인한다. 예전에 "제가 얼마"나 "더라고요"가 잘린 적이 있다.
6. **화면 맞추기**: 1104×900 영역을 y=90에서 잘라 1080×880으로 줄인다. 측면 카메라(왼쪽에 흰 슬라이드)가 나오는 구간은 x를 408에서 816으로 옮긴다.
7. **표지**: 눈을 뜨고 있는 정면 장면을 골라 0.5초짜리 정지 화면을 맨 앞에 붙인다. 인스타그램 썸네일이 첫 장면이 된다.
   - 첫 장면에 페이드인을 넣지 않는다. 검은 썸네일이 된다.
8. **올리기**: 저장소 `media/<설교>/`에 커밋한 뒤 raw 주소로 캔바에 올린다. 게시는 목사님이 요청할 때만 한다.

## FFmpeg 명령

### 구간 자르기 (앞뒤로 짧은 소리 페이드)
```bash
ffmpeg -ss 1495.0 -i src.mp4 -t 62.4 -vf fps=30 \
  -af "afade=in:st=0:d=0.12,afade=out:st=62.3:d=0.1" \
  -c:v libx264 -preset veryfast -crf 19 -c:a aac -b:a 160k part.mp4
```

### 여러 조각 이어 붙이기 (버벅거린 구간을 빼고 앞뒤를 이을 때)
```bash
ffmpeg -i a.mp4 -i b.mp4 -filter_complex "[0:v][0:a][1:v][1:a]concat=n=2:v=1:a=1[v][a]" \
  -map "[v]" -map "[a]" -c:v libx264 -crf 19 -c:a aac joined.mp4
```
- 말을 되풀이하거나 다시 시작한 부분을 찾을 때는, 받아쓰기에서 같은 말이 연달아 나오는 곳을 본다. 예: MARK ① 0:02–0:08 "심장이 조여오는… 심장이 갑자기".
- 이은 자리는 반드시 귀로 다시 들어 본다. 받아쓰기를 다시 돌려 문장이 자연스러운지도 확인한다.

### 침묵 찾기 (말 사이 긴 공백 빼기)
```bash
ffmpeg -i clip.mp4 -af silencedetect=noise=-35dB:d=0.6 -f null - 2>&1 | grep silence_
```
- 0.6초 넘는 공백을 후보로 보고, 설교의 쉼표 같은 자연스러운 멈춤은 남긴다.

### 소리 크기 맞추기 (클립마다 크기를 같게)
```bash
ffmpeg -i clip.mp4 -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:v copy -c:a aac -b:a 160k out.mp4
```

### 화면 비율 바꾸기
```bash
# 16:9 → 9:16 (유튜브 쇼츠, 가운데 기준)
ffmpeg -i in.mp4 -vf "crop=ih*9/16:ih,scale=1080:1920" -c:a copy shorts.mp4
# 16:9 → 4:5 (인스타그램 피드)
ffmpeg -i in.mp4 -vf "crop=ih*4/5:ih,scale=1080:1350" -c:a copy feed.mp4
```
- 설교자가 가운데에 없으면 crop의 x 값을 받아쓰기 시간대별로 옮긴다. 측면 카메라 구간이 그렇다.

### 장면 바뀜 찾기 (카메라 전환 구간 확인)
```bash
ffmpeg -i in.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep showinfo
```

### 받아쓰기용 소리 뽑기
```bash
ffmpeg -i clip.mp4 -ac 1 -ar 16000 clip.wav
```

## 원칙
- 받아쓰기가 먼저고, 자르기는 그다음이다. 귀로 확인하기 전에는 확정하지 않는다.
- 한 번에 하나씩 확인한다. 클립마다 첫 장면, 10초, 30초, 50초 장면을 한 장에 모아 본다.
- 원본은 건드리지 않는다. 자른 조각은 scratchpad에, 완성본만 `media/`에 둔다.
- 캔바 내보내기는 한 번에 하나씩 한다. 동시에 여러 개를 하면 요청 한도에 걸린다.
