argument-hint: "(검색 키워드 + 붙여넣은 상위노출 글 1~5개)"
---

입력: $ARGUMENTS

규칙: 사용자가 제공한 글로만 분석한다. 자동 수집·크롤링 금지. URL만 있으면 본문 붙여넣기를 요청한다.
입력이 비어 있으면 "검색 키워드와 상위노출 글 본문(1~5개)을 붙여넣어 주세요"라고 요청하고 멈춘다.

글마다 측정:
- 제목: 글자 수, 키워드 위치(앞/중간/뒤), 구조 패턴(예: "제품명 + 사용기간 + 결과")
- 본문 글자 수(공백 제외/포함), 사진 수(사용자가 알려준 경우), 소제목 수, 인용구 수
- 메인 키워드 등장 횟수, 첫 문단 키워드 여부
- 도입 후킹 유형, 단점 언급 여부, CTA 유형

결과를 `data/trends.md`의 "키워드별 세팅값" 표에 **키워드별로 누적** 추가하고, 평균·범위를 계산해
해당 키워드(또는 카테고리) 글을 쓸 때의 추천 세팅값(글자 수 범위, 사진 수, 제목 길이, 소제목 수)을 갱신한다.
마지막에 추천 세팅값과 CLAUDE.md 기본 세팅과의 차이를 3줄로 요약한다.
