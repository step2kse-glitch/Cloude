argument-hint: "(붙여넣은 글 또는 비워두면 붙여넣기 요청)"
---

입력: $ARGUMENTS

규칙: 사용자가 붙여넣은 글로만 학습한다. 네이버 블로그 URL만 주면 WebFetch를 시도하지 말고 본문 붙여넣기를 요청한다(도메인 차단). 자동 수집 금지.

입력이 비어 있으면 "벤치마킹할 글 본문을 붙여넣어 주세요"라고 요청하고 멈춘다.

분석 항목 (문장을 베끼지 말고 **구조만** 추출 — 유사문서 방지):
1. 말투: 어미 비율(해요/합니다/반말), 문장 길이, 감탄·의성어·이모지 빈도, 자주 쓰는 연결어
2. 도입: 후킹 유형(손실 회피/현장 몰입/반전/공감), Yes-set 구성, 결론 예고 방식
3. 권위·신뢰 장치: 경력·사례량·솔직함 표현 방식
4. 구성: 소제목 흐름, 사진 배치 리듬, 인용구 용도, 체크리스트 사용
5. 심리 전략: 단점 노출 방식, 비추천 대상 언급, CTA 방식
6. 이 블로그(살림 13년차·4남매 엄마 화자)에 적용할 것 / 적용하지 말 것

결과를 `data/style-profile.md`에 **누적** 추가한다 (날짜, 출처 설명 한 줄, 위 항목). 기존 학습과 충돌하면 "충돌 메모"로 남기고 사용자에게 어느 쪽을 따를지 묻는다.
마지막에 학습 요약 5줄을 보여준다.
