# 사사기 웹 주석 정리 (목사님 제공, 2026-10-06)

Logos가 아니라 웹 주석에서 확인한 내용입니다. 히브리어 풀이는 Logos에서 원어를 한 번 더 확인할 것.

## 전체 흐름
- 사사들이 점점 나빠진다(BibleProject). 옷니엘 → 기드온(살인) → 입다(딸을 바침) → 삼손(폭력, 교만). 구원자들도 함께 무너진다.
- 1장이 출발점. 1:28처럼 쫓아내지 않고 노역만 시킨 타협 때문에 순환이 시작된다(데일 랄프 데이비스, 게리 인릭). 인릭: "부분적인 방어는 방어가 아니다." 2:3 "옆구리의 가시"와 함께.

## 구절별
- 2:10 — 수 24:31(여호수아를 본 세대는 여호와를 섬김)과 대비. 한 세대 만에 신앙이 끊김.
- 6:12 — 6:11 기드온은 미디안이 무서워 포도주 틀에서 밀을 타작. "큰 용사"는 반어. 호칭은 지금 모습이 아니라 하나님이 함께하심에서 나옴.
- 8:23 — 말로는 왕을 거절, 8:27 에봇을 만들어 온 이스라엘이 음란하게 섬김. 고백과 행동의 어긋남.
- 9:15 — 가시나무는 그늘이 없고 가지도 약한데 그늘을 약속하며 불로 위협. 아비멜렉.
- 10:16 — 직역 "그의 영혼이 짧아졌다"(카차르 네페쉬), 더는 참지 못하심. 10:13–14 "다시는 구원하지 아니하리라" 하신 거절을 스스로 거두심. 16:16 들릴라의 조름에 "삼손의 마음이 번뇌하여 죽을 지경"과 같은 표현.
- 12:6 — 십볼렛 = "이삭" 또는 "흐르는 물". 요단 나루터에 맞음. 에브라임은 쉰(ש)을 사멕(ס)으로 발음(반즈, 길, 카일-델리치). 엘리코트: 사소한 차이를 과장해 가르는 관용어가 됨. 4만 2천의 "천"은 부대·씨족 단위일 수 있음.
- 13:18 — "기묘" 펠리(פלאי), 사 9:6 "기묘자"(펠레)와 같은 어근. 엔듀링워드: 성육신 이전의 그리스도.
- 14:4 — 하나님이 삼손의 죄를 승인하신 것이 아니라 허락하고 뒤집어 사용하심. 위어스비: "하나님이 다스리지 못하게 하면, 그분은 뒤엎어 다스리신다." 14:3 "내 눈에 옳으니" → 21:25 "자기의 소견에 옳은 대로".
- 15:19 — 학고레 = "부르는 자"(자고새 해석도 있음). "우묵한 곳" 막테쉬 = 절구, 오목한 그릇. "정신이 회복되어"에 루아흐(영, 숨).
- 16:22 — 삼손은 히 11:32 믿음의 사람 목록에 오름. 실패한 사람에게도 은혜가 다시 자란다.
