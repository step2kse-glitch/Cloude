# 네이버 블로그 자동 작성 툴 + 릴스 스튜디오 — 살림 꿀템

사진 몇 장과 한 줄 메모를 주면, Claude Code가 사진을 직접 보고 네이버 상위노출 공식에 맞춰 글을 쓰고,
승인하면 **임시저장까지** 해줍니다. 발행 버튼은 항상 내가 누릅니다.

## 가장 쉬운 설치 (Mac)

1. GitHub 저장소 페이지 → 초록색 **Code** 버튼 → **Download ZIP** → 다운로드 폴더에서 압축 풀기 (`Cloude-main` 폴더)
2. Node.js가 없으면 nodejs.org 에서 LTS(.pkg) 설치
3. **터미널** 앱(Spotlight에서 "터미널" 검색)을 열고 아래 한 줄 붙여넣기 → 엔터:
   ```
   cd ~/Downloads/Cloude-main && bash setup.command
   ```
   마지막에 뜨는 크롬 창에서 네이버 로그인
4. 핸드폰으로 쓰려면 터미널에서:
   ```
   cd ~/Downloads/Cloude-main && bash start-phone.command
   ```
   → 핸드폰 Claude 앱 → Claude Code 에서 이 맥 세션 선택 → `/write ...`
   - 터미널 창을 닫으면 연결이 끊겨요. 실행 중엔 맥이 잠자기 하지 않아요(뚜껑은 열어두기).
   - 사진은 맥의 `input/photos/` 에 있어야 해요 (아이폰이면 AirDrop, 또는 iCloud Drive 폴더 연결).

## 가장 쉬운 설치 (Windows, 더블클릭)

1. GitHub 저장소 페이지 → 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기
2. 폴더 안의 `setup.bat` 더블클릭 → 안내대로 (마지막에 뜨는 크롬 창에서 네이버 로그인)
3. 핸드폰으로 쓰려면 `start-phone.bat` 더블클릭 → 핸드폰 Claude 앱 → Claude Code 에서 이 컴퓨터 세션 선택 → `/write ...`
   - 컴퓨터는 켜둔 상태(절전 해제)여야 해요. 사진은 컴퓨터의 `input/photos/` 에 있어야 해요
     (구글 드라이브 폴더와 연결해 두면 핸드폰으로 찍어 바로 넣을 수 있어요).

## 설치 (터미널로 직접, 최초 1회)

준비물: Node.js(LTS), Claude Code, Claude 유료 구독, 네이버 계정

```bash
git clone https://github.com/step2kse-glitch/cloude.git
cd cloude
npm install
npx playwright install chromium
claude
```

Claude Code 채팅에서:

```
/setup-login
```

크롬 창이 뜨면 직접 네이버에 로그인하세요 (패스키 가능). 비밀번호는 저장되지 않고, 로그인 세션만 `naver-profile/`에 남습니다.
**`naver-profile/` 폴더는 절대 공유·업로드하지 마세요.**

## 평소 사용법

1. `input/photos/` 에 사진을 넣는다 (영상은 `input/videos/`)
2. 채팅: `/write 다이소 배수구 클리너, 내돈내산, 2주 써보니 냄새 끝`
3. 초안·검수 보고 확인 → 승인 → 네이버 "저장 글"에서 확인 후 직접 발행

| 명령 | 하는 일 |
|---|---|
| `/write` | 사진 분석 → 질문 → 초안 → 승인 후 임시저장 |
| `/learn-style` | 벤치마킹 글을 붙여넣으면 말투·구성 학습 |
| `/analyze-trends` | 상위노출 글을 붙여넣으면 글자 수·사진 수 등 세팅값 추출 |
| `/setup-login` | 네이버 로그인 다시 하기 |
| `/reels` | 사진·영상 → 릴스 스토리보드 → 승인 후 세로 영상 렌더링 |


## 🏢 AI 오피스 (스튜디오 첫 화면)

AI 직원들이 일하는 사무실 화면이에요. 직원을 누르면 하는 일과 지금 상태가 보여요.

| 직원 | 하는 일 |
|---|---|
| ✍️ 블로그 작가 | "다이소 배수구 클리너, 내돈내산, 2주 써보니 냄새 끝"처럼 지시 → 블로그 초안 → **결재함**에서 승인하면 네이버 임시저장 |
| 🎬 릴스 PD | 릴스 스토리보드 (만들기 화면으로 연결) |
| 🎞️ 영상 편집자 | 자막·음악 넣어 영상 만들기, 게시 대기 알림 |
| 🔎 사실 검수관 | 글·영상 속 숫자가 자료에 있는지 대조 |
| 🛡️ 개인정보 지킴이 | 모자이크 현황 |
| 🗂️ 비서 | 질문에 답하고 현황 정리 (파일은 안 건드림) · **비서 브리핑**은 요금 없이 바로 |

- **보고함**: 직원이 끝낸 일 · **결재함**: 사장님 승인이 필요한 일 (임시저장·영상 만들기·게시) · **실시간**: 최근 활동
- 발행·게시는 지금처럼 사장님이 직접 해요.

## 릴스 스튜디오 (사진·촬영본 → 세로 릴스/쇼츠)

찍어서 올리면 AI가 스토리보드(컷·자막·후킹 문구)를 짜고, 확인 누르면 **1080×1920 자막·배경음악 영상**이 나옵니다.
분야는 **살림템 후기 / 설교·말씀 / 정보 / 기본** 4가지이고, 분야마다 필터·자막 스타일이 자동으로 맞춰집니다.

| 분야 | 기본 필터 | 자막 | 효과 |
|---|---|---|---|
| 살림템 후기 | 화사하게 | 굵은 외곽선 | 스르륵 |
| 설교·말씀 | 무드(차분) | 명조 감성 + 금색 강조, 말씀 카드·출처 | 스르륵 |
| 정보 | 선명하게 | 대형 타이포 + 상단 고정 제목 | 한 단어씩 |

- 필터 10종: 원본·화사하게·따뜻하게·시원하게·선명하게·필름·흑백·몽글몽글·무드·노을빛 (컷마다 다르게도 가능)
- 자막 6종: 굵은 외곽선·반투명 박스·형광펜·명조·대형 타이포·미니멀 / 효과 4종: 없음·스르륵·올라옴·한 단어씩
- 자막에서 `*단어*` 로 감싸면 강조 색
- 설교 릴스의 성경 구절은 **붙여넣은 본문 그대로만** 씁니다 (AI가 기억으로 인용하지 않음)
- 새 자막 스타일: 깔끔·흰 카드·에디토리얼 명조·시네마 + 강조색(브랜드 색) + 레터박스. 폰트는 Pretendard·고운바탕 자동 설치
- **길이 15 / 30 / 60초** 선택. 배경음악이 짧아도 이음새 없이 이어 붙이고, 말소리가 나오면 자동으로 작아져요
- **🎙 AI 나레이션 (Fish Audio, 선택)**: fish.audio에서 API 키를 받아 설정 탭에 넣고 목소리 ID를 고르면, 컷마다 나레이션을 읽어주고 자막도 목소리에 맞춰 자동으로 나와요.
  요금은 Fish Audio에 글자 수만큼 (같은 문장은 다시 안 만듦). 키는 내 PC `data/voice.local.json`에만 저장 — 남에게 보내지 마세요.
  목소리 복제는 본인·허락받은 목소리만.
게시는 자동으로 하지 않아요 — 받아서 인스타·유튜브 앱에서 직접 올립니다.

1. 켜기: 맥 `bash start-studio.command` / 윈도우 `start-studio.bat` 더블클릭
2. 창에 뜬 **핸드폰에서: http://192.168.x.x:4321/?key=…** 주소를 같은 와이파이의 핸드폰 브라우저로 열기 (홈 화면에 추가하면 앱처럼 쓸 수 있어요)
3. **만들기** → 사진/촬영 영상 고르기 · 주제 · 협찬 여부 · 메모 → "자료 올리고 시작하기"
4. 1~3분 뒤 AI 스토리보드 도착 → 자막·길이·움직임 수정 → **영상 만들기** (빠른 미리보기도 가능)
5. 자동 검증(해상도·길이·소리·협찬 표기) + 장면별 확인 시트를 보고 → **게시·예약** 탭에서 문구 복사·영상 받기 → 직접 업로드

| 탭 | 하는 일 |
|---|---|
| 내 영상 | 작업 목록·상태 (AI 구성 중 / 검토 대기 / 완성 / 게시 완료) |
| 만들기 | 자료 올리기 + AI 스토리보드 요청 |
| 게시·예약 | 올릴 날짜, 업로드 전 체크리스트, 인스타·유튜브 문구 복사, 영상 다운로드, 올린 곳 표시 |
| 설정 | 영상 합성·자막·Claude 연결 상태, 저장 공간, 배경음악 올리기, 핸드폰 접속 주소 |

- 채팅으로도 가능: `input/photos/`·`input/videos/`에 넣고 `/reels 다이소 배수구 클리너, 내돈내산, 2주 써보니 냄새 끝` / `/reels 설교 마태복음 11:28 (본문 붙여넣기) 쉼`
- 배경음악은 저작권 걱정 없는 음원(유튜브 오디오 보관함 등)을 `input/bgm/`에 (또는 설정 탭에서 업로드)
- 자막 폰트를 바꾸려면 ttf/otf 하나를 `assets/fonts/`에 넣기 (상업 이용 가능한 폰트로)
- 아이 얼굴·송장·동호수는 AI가 찾아 모자이크하지만, 업로드 전 꼭 눈으로 확인하세요
- 아이폰 HEIC 사진은 아직 못 써요 → 설정 > 카메라 > 포맷 > "높은 호환성"
- 접속 주소(key)는 남에게 보내지 마세요. 새로 발급하려면 `drafts/reels/.studio-key` 삭제 후 다시 켜기

## 막힐 때

- `스크립트를 실행할 수 없으므로` → PowerShell에서 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 후 `Y`
- `claude 용어가 인식되지 않습니다` → 터미널을 껐다 켜기
- `&&` 오류 → 명령을 한 줄씩 실행
- 그 외 모든 오류 → 오류 메시지를 그대로 Claude Code 채팅에 붙여넣기

## 주의

- 브라우저 자동화는 네이버 약관상 회색지대입니다. 본인 계정으로, 하루 1~2건만.
- 이 툴은 "초안 공장"이지 "무인 발행기"가 아닙니다. 발행 전 최종 확인과 글에 대한 책임은 작성자에게 있습니다.
- 협찬 글은 공정위 지침에 따라 협찬 표기가 자동으로 들어갑니다. 발행 전 꼭 눈으로 확인하세요.
