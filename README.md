# 네이버 블로그 자동 작성 툴 — 살림 꿀템

사진 몇 장과 한 줄 메모를 주면, Claude Code가 사진을 직접 보고 네이버 상위노출 공식에 맞춰 글을 쓰고,
승인하면 **임시저장까지** 해줍니다. 발행 버튼은 항상 내가 누릅니다.

## 가장 쉬운 설치 (Mac)

1. GitHub 저장소 페이지 → 초록색 **Code** 버튼 → **Download ZIP** → 다운로드 폴더에서 압축 풀기 (`Cloude-main` 폴더)
2. Node.js가 없으면 nodejs.org 에서 LTS(.pkg) 설치
3. **터미널** 앱(Spotlight에서 "터미널" 검색)을 열고 아래 한 줄 붙여넣기 → 엔터:
   ```
   cd ~/Downloads/Cloude-main && bash setup.command
   ```
   마지막에 뜨는 크롬 창에서 네이버 로그인
4. 핸드폰으로 쓰려면 터미널에서:
   ```
   cd ~/Downloads/Cloude-main && bash start-phone.command
   ```
   → 핸드폰 Claude 앱 → Claude Code 에서 이 맥 세션 선택 → `/write ...`
   - 터미널 창을 닫으면 연결이 끊겨요. 실행 중엔 맥이 잠자기 하지 않아요(뚜껑은 열어두기).
   - 사진은 맥의 `input/photos/` 에 있어야 해요 (아이폰이면 AirDrop, 또는 iCloud Drive 폴더 연결).

## 가장 쉬운 설치 (Windows, 더블클릭)

1. GitHub 저장소 페이지 → 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기
2. 폴더 안의 `setup.bat` 더블클릭 → 안내대로 (마지막에 뜨는 크롬 창에서 네이버 로그인)
3. 핸드폰으로 쓰려면 `start-phone.bat` 더블클릭 → 핸드폰 Claude 앱 → Claude Code 에서 이 컴퓨터 세션 선택 → `/write ...`
   - 컴퓨터는 켜둔 상태(절전 해제)여야 해요. 사진은 컴퓨터의 `input/photos/` 에 있어야 해요
     (구글 드라이브 폴더와 연결해 두면 핸드폰으로 찍어 바로 넣을 수 있어요).

## 설치 (터미널로 직접, 최초 1회)

준비물: Node.js(LTS), Claude Code, Claude 유료 구독, 네이버 계정

```bash
git clone https://github.com/step2kse-glitch/cloude.git
cd cloude
npm install
npx playwright install chromium
claude
```

Claude Code 채팅에서:

```
/setup-login
```

크롬 창이 뜨면 직접 네이버에 로그인하세요 (패스키 가능). 비밀번호는 저장되지 않고, 로그인 세션만 `naver-profile/`에 남습니다.
**`naver-profile/` 폴더는 절대 공유·업로드하지 마세요.**

## 평소 사용법

1. `input/photos/` 에 사진을 넣는다 (영상은 `input/videos/`)
2. 채팅: `/write 다이소 배수구 클리너, 내돈내산, 2주 써보니 냄새 끝`
3. 초안·검수 보고 확인 → 승인 → 네이버 "저장 글"에서 확인 후 직접 발행

| 명령 | 하는 일 |
|---|---|
| `/write` | 사진 분석 → 질문 → 초안 → 승인 후 임시저장 |
| `/learn-style` | 벤치마킹 글을 붙여넣으면 말투·구성 학습 |
| `/analyze-trends` | 상위노출 글을 붙여넣으면 글자 수·사진 수 등 세팅값 추출 |
| `/setup-login` | 네이버 로그인 다시 하기 |
| `/auction` | 법원경매 물건 찾기·분석 리포트 (아래 참고) |

## 법원경매 AI 분석 (`auction/`)

조건만 말하면 AI가 경매 물건을 찾아 **한 장의 리포트**로 정리합니다.

- **얼마에 써낼지**: 보수 / 추천 / 상한(넘으면 포기) 입찰가
- **얼마를 넣어야 하는지**: 입찰보증금, 잔금일 필요 현금(대출·세금·이전비·명도·수리 포함), 내 현금으로 가능한 최대 낙찰가
- **권리분석**: 말소기준권리, 인수되는 권리, 임차인 대항력·배당·인수 보증금 (규칙이 코드로 고정돼 매번 같은 기준)
- **명도**: 점유자 유형별 절차·비용·기간
- **어떻게 쓰는 게 나은지**: 매도 / 전세 / 월세 / 실거주를 같은 표에서 비교 (넣을 돈·묶이는 돈·이익·연수익률·세금·위험)
- **내 집 찾기**: 실거주면 출퇴근·학교 기준 후보 순위 + 급매 대비 절약액 + 입주 예상일
- **진행 일정**: 임장 → 입찰 준비물 → 매각허가 → 잔금·인도명령 → 명도

입찰은 항상 내가 법원에 가서 합니다. 프로그램은 사이트를 읽기만 해요.

### 사용법 — 화면으로 (가장 쉬움)

1. **`경매분석.command`(맥) / `경매분석.bat`(윈도우) 더블클릭** → 브라우저에 **"내 경매 비서"** 화면이 열려요
2. 처음이면 홈에서 **🧪 샘플로 체험** → 가상 물건 6건으로 둘러보기
3. **⚙️ 설정**에서 목적·현금·대출·찾는 지역을 입력 (저장하면 모든 물건이 다시 계산돼요)
4. **🔎 AI로 물건 찾기** 또는 **➕ 사건번호로 추가** → AI가 서류를 읽고 분석
   - 첫 실행만 크롬 창이 뜨면 직접 검색하고 관심 물건 상세 화면을 열어 주세요
5. 물건을 누르면 탭으로 정리돼 있어요: 요약 · **권리관계** · 입찰가·돈 · **경쟁(낙찰가율)** · 명도 · **활용법** · 일정 · 기록하기
6. 임장 후 **기록하기** 탭에 시세·전월세·관리비·낙찰 사례를 적으면 바로 다시 계산돼요. "4억 9000만"처럼 써도 돼요
7. 입찰일이 지나면 **입찰 결과**를 기록 → **🎯 적중률**에 내 추천가가 얼마나 맞았는지 쌓여요
8. **📅 일정**에서 `.ics` 파일을 받아 구글·아이폰 캘린더에 가져오기
9. **✍️ 콘텐츠**에서 분석한 물건을 블로그 글·유튜브 쇼츠·롱폼 원고로 변환 (주소의 호수·개인정보는 자동 제외)

| 화면 | 하는 일 |
|---|---|
| 🏠 홈 | 예산·관심물건·2주 일정·등급 분포·빠른 작업 |
| 📋 물건 | 등급·관심 필터, 태그 검색(예: `대항력`), 정렬 |
| 🗺 지도 | 물건 위치를 등급 색 핀으로 표시, 핀 누르면 요약 · 카카오맵·네이버지도·로드뷰 바로가기 |
| 📅 일정 | 월 달력 + 캘린더 파일 내보내기 |
| 🎯 적중률 | 내 추천가 vs 실제 낙찰가 (±5/10/15/20%, 치우침) |
| ✍️ 콘텐츠 | 블로그·쇼츠·롱폼 원고 + AI 다듬기 |
| 🤖 AI 작업 | 실행 중인 AI 작업과 기록 |
| ⚙️ 설정 | 글자 크기·화면 색(밝게/어둡게) · 지도 키 · 목적·돈·찾는 물건·제외 위험·실거주 기준·비용 추정치 |

**네이버 블로그에 올리기**: 물건 → **📝 블로그 글** → **블로그 초안 만들기** → 미리보기 확인 → **✅ 이대로 네이버에 임시저장**.
분석 카드 이미지 5장(요약·권리 타임라인·입찰가·활용법·체크리스트)과 글·태그가 임시저장되고, **발행은 네이버 앱에서 직접** 눌러요.
처음 한 번 **설정 → 📝 네이버 블로그**에서 올릴 블로그를 고르고 로그인하세요. 살림 블로그와 섞이면 주제가 흐려지니 **경매 전용 블로그**를 추천해요.
채팅으로는 `/auction 화성 아파트 5억 이하 투자, 좋은 물건은 블로그까지` 처럼 한 번에 맡길 수 있어요 (임시저장 전에 한 번 확인을 물어요).

**매일 1건 "1억으로 경매" 자동 준비**: `매일경매-켜기.command`(맥) / `매일경매-켜기.bat`(윈도우) 를 한 번 더블클릭하면
매일 아침 7:30에 AI가 물건을 찾고 → 현금 1억(대출 60% 가정)으로 가능한 A·B 등급 물건 1건을 골라 → 블로그 글·카드 이미지를 준비해요.
조건에 맞는 물건이 없으면 그날은 패스. 준비된 글은 웹 화면 홈의 **📝 오늘의 블로그** 카드에서 **✅ 승인하고 임시저장**
(또는 채팅으로 "오늘 거 올려줘") → 네이버 앱에서 발행. 끄려면 `매일경매-끄기`. 컴퓨터가 켜져 있어야 해요.

**글자 크기**: 화면 오른쪽 위 **가가** 버튼을 누를 때마다 작게 → 보통 → 크게 → 아주 크게 → 최대 (설정에서 화면 색도 바꿀 수 있어요)

**지도**: 🗺 지도에서 **📍 위치 찾기**를 누르면 주소로 핀을 찍어요. 기본은 무료 OpenStreetMap(한국 주소는 동네 단위로 찍히는 경우가 많아요)이고,
설정에 **카카오 REST API 키**(developers.kakao.com, 무료)를 넣으면 번지까지 정확해져요. 핀이 틀리면 물건 → 위치 탭 → **지도에서 직접 찍기**.

**핸드폰으로 보기 (선택)**: 같은 와이파이에서 터미널에 `node auction/src/cli.js web --lan` 을 실행하면 나오는
"같은 와이파이 핸드폰" 주소를 핸드폰 브라우저에 입력하세요. 주소에 비밀 토큰이 들어 있어 그 주소를 아는 사람만 열 수 있어요.
카페 같은 공용 와이파이에서는 쓰지 마세요.

**채팅으로 쓰기**: Claude Code에서 `/auction 화성 아파트 5억 이하 투자`, `/auction 2026타경12345`, `/auction 임장 결과: ...`

| 폴더 | 내용 |
|---|---|
| `auction/config/criteria.json` | 내 조건 (채팅으로 말하면 AI가 수정) |
| `auction/config/*.json` | 세율·소액임차인 기준·명도/임대 비용 추정치 — 법 개정 시 갱신 |
| `auction/knowledge/` | 권리분석·입찰 절차·내 집 찾기 가이드 |
| `auction/src/` | 프로그램 (`node auction/src/cli.js` 로 명령 목록) |
| `auction/workspace/` | 수집 원본·물건 데이터·리포트 (내 컴퓨터에만, 업로드 안 됨) |

⚠ 리포트는 참고용이며 법률·세무 자문이 아닙니다. 세율·비용은 단순화한 추정치라 입찰 전 꼭 재확인하세요.

## 막힐 때

- `스크립트를 실행할 수 없으므로` → PowerShell에서 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 후 `Y`
- `claude 용어가 인식되지 않습니다` → 터미널을 껐다 켜기
- `&&` 오류 → 명령을 한 줄씩 실행
- 그 외 모든 오류 → 오류 메시지를 그대로 Claude Code 채팅에 붙여넣기

## 주의

- 브라우저 자동화는 네이버 약관상 회색지대입니다. 본인 계정으로, 하루 1~2건만.
- 이 툴은 "초안 공장"이지 "무인 발행기"가 아닙니다. 발행 전 최종 확인과 글에 대한 책임은 작성자에게 있습니다.
- 협찬 글은 공정위 지침에 따라 협찬 표기가 자동으로 들어갑니다. 발행 전 꼭 눈으로 확인하세요.
